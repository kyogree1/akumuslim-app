# Backend AkuMuslim

Backend Node.js + Express untuk data bookmark, catatan ayat, dan progres membaca. Data Al-Qur'an tetap diambil oleh Flutter dari API eQuran.

Struktur awal:

- `src/config`: koneksi dan konfigurasi database MySQL.
- `src/controllers`: handler request dan response API.
- `src/routes`: definisi endpoint API.
- `src/services`: query dan aturan bisnis.
- `src/middleware`: validasi serta penanganan error.
